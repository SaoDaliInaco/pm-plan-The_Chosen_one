# Lab-03: life cycle and methodology · Realtime Quiz

The Realtime Quiz project adopts a hybrid life cycle methodology combining predictive predictive planning gates (G1-G4) with agile Scrum delivery sprints (14-week schedule). This structure provides the rigid governance and timeline certainty required by the department sponsor while allowing iterative flexibility during core feature development.

Sponsor oversight is maintained through rigorous stage gate reviews, strict management-by-exception tolerances, and bi-weekly sprint reviews where working increments are demonstrated directly against predefined acceptance criteria.
